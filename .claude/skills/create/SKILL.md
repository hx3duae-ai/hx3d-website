# /create <topic>

1. Ask for the format if it is not clear: reel script, carousel, caption, story, newsletter, WhatsApp broadcast, or infographic outline.
2. Search `hx-brain/wiki/` for the topic (then `wiki/history/` and `hx-os/data/`). Use only facts, prices and examples found there and cite which pages you used at the end.
3. Apply:
   - `hx3d-brand-style`: voice (Abdulaziz, Gulf Arabic), colours, fonts, 9:16 specs, CTA keyword plus PDF.
   - `virality` for any reel: three hooks, pick one, line-by-line script with a visual on every line.
   - `social` for platform rules (carousel slide count, caption length).
4. Output the finished piece, ready to post, then: sources used, and one variation.
5. Offer to save it to `hx-brain/output/<date>-<slug>.md`. Never publish anything yourself.
