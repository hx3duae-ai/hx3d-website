# اسلوبي — أسلوب فيديوهات HX 3D

مرجع ثابت لأي فيديو أو صورة مصغّرة أو ملف PDF جديد لـ HX 3D. أي شي جديد يمشي على هذا الملف.

---

## 1. المقاس والتصدير
- **المقاس:** 9:16 دائماً (1080×1920). لا تسوي 16:9 إلا إذا انطلب.
- **المدة:** تقريباً 50–70 ثانية.
- **الفيديو:** H.264 ‏Main 4.1، ‏30 فريم، إطار رئيسي كل ثانية، CRF ‏19، ‏yuv420p، ‏faststart (عشان ما يعلّق على الجوال).
- **الصوت:** AAC ستيريو 44.1 كيلو، ‏160 ك.

## 2. الألوان
- **وردي `#FF66B2`** + **أبيض** + **أسود** فقط.
- **ممنوع الأصفر.** ولا خلفيات سوداء كاملة.
- رمادي فاتح مسموح للتفاصيل والخطوط الثانوية.

## 3. الخطوط والكتابة
- **Cairo** (عريض 900 للعناوين، 700 للنص). **Aref Ruqaa** للملاحظات بخط اليد.
- عربية سليمة 100%: حروف متصلة، من اليمين لليسار، بدون أخطاء إملائية.
- النصوص تنكتب بالكود، **مو** داخل صور مولّدة بالذكاء الاصطناعي (عشان ما تخرب الحروف).
- **ما في نص فوق نص** ولا عنصر يغطّي على كلمة.
- الكلمة المهمة في العنوان: **خلفية وردية** تنرسم عليها وقت ما تنقال.

## 4. الشكل العام (Editorial Scrapbook / VOX)
- **الخلفية:** ورق مربعات فاتح، مجعّد شوي، مع ظل خفيف عند الأطراف.
- **العناصر قصاصات ورق:** حواف ممزّقة، ظل ناعم تحتها، شريط لاصق، مشابك ورق.
- **ملصقات صور حقيقية** (طابعات، بكرات، Benchy، فوهة…) مقصوصة بحد أبيض وظل — مثل الريلز المرجعية.
- **رسومات خطية يدوية:** أسهم متقطّعة، علامة استفهام، ترمومتر، ترس، بطاقة سعر، نجوم، خط وردي متموّج تحت العنوان.
- **سلسلة خطوات** في أسفل المشهد: «الخطوة ← الخطوة ← **النتيجة**» (آخر وحدة وردية).
- **شارة فصل** لكل نقطة: «01 السطح»، «02 الخيط»…
- شعار **HX 3D** صغير ثابت في الزاوية، وشريط تقدّم وردي فوق.
- **مساحات فاضية واضحة.** نقطة تركيز وحدة أو ثنتين بالمشهد، مو زحمة.

## 5. الحركة (Motion)
- العناصر تظهر **تدريجياً**: الورقة ← الرسم ← السهم ← المعلومة.
- كاميرا هادئة: تقريب بطيء، انزلاق خفيف، دوران بسيط جداً.
- انتقال المشاهد: سحب الورقة لفوق/جنب.
- الرسومات نفسها تتحرك: البكرات تدور، الفوهة تتحرك، القطرات تتنطط، الأعمدة تنبض.
- **ممنوع:** اهتزاز كاميرا، انتقالات سريعة، مؤثرات مبالغ فيها.

## 6. «نجم» — الشخصية اللي تشرح
- **الاسم:** نجم. نجمة نصّها أسود ونصّها وردي. الملفات: `video-design/characters/najm/`.
- **المكان:** أسفل يسار الفيديو، بحجم تقريباً 420×446، وتطلع من تحت الشاشة في أول ثانية.
- **تتحرك على معنى الكلام**، مو عشوائي. أمثلة:
  - البداية: **تلويح** ← بعدها **إشارة**.
  - «أولاً / المشكلة الأولى / ثالثاً…»: **رفع إصبع** دائماً (47 ← 60 ← 47). «ثانياً»: إصبعين (62).
  - معلومة على الشاشة: **تأشّر** عليها (51، 70، 160).
  - «أقوى / قوة»: **عضلات** (56، 57).
  - «تالفة / تتشوّه / اهتزاز / تحتار»: **هزّ كتفين** (63، 168، 173).
  - «تسمع / تفكّر»: **يد على الراس** (170، 55).
  - «تمام / دقيق / جاف»: **علامة OK** (204، 205).
  - «أسهل / صحّح»: **إبهام** (66، 186، 187).
  - «عالية / مجتمع كبير»: **يدين لفوق / تلويح باليدين** (198، 179، 180).
  - «السرعة / ستتغيّر»: **قفز** (190، 191).
  - النهاية: إبهامين ← احتفال ← تلويح وداع.
- **القواعد:** تتغيّر الحركة كل ثانية تقريباً مع جملة جديدة. اهتزاز خفيف 2–3 بكسل. انتقال مباشر مع نطّة صغيرة (**بدون دمج** يخلّيها مكرّرة/مغبّشة). ظل ناعم تحت رجلينها.
- **لا تخلط اللوحات** في نفس المقطع. استخدم **s1 و s5** (نفس شكل نجم وأعلى دقة). تجنّب s2 / s3 / s4 / s8 (شكل مختلف).
- راجع صورة الرقم قبل استخدامه (بعض الأرقام حركتها غير المتوقع).

## 7. الصوت
- **التعليق:** صوت رجالي إماراتي، **عبدالعزيز** من منصت (`XIZ1vZnDV6J0LjNdMSJebjco`)، سرعة 0.9، ثبات 0.6.
- النص **بالفصحى** (العربية السليمة)، وتسجيل **واحد متصل** للفيديو كامل (مو مقاطع منفصلة).
- **بدون أي معالجة** للصوت (لا رفع نبرة ولا EQ ولا قصّ) — بس توحيد المستوى (‎-14 LUFS).
- المصطلحات الإنجليزية: PLA تنقال تمام؛ PETG نطقها غير مضبوط تماماً.
- **ممنوع الموسيقى.**
- **ممنوع صوت «بوب» و«تق تق» والنقرات** (تنسمع كأنها موسيقى).
- المسموح: **حفيف انتقال** بين المشاهد + **صوت قلم** لما ينرسم خط/تمييز، بمستوى منخفض.
- ترجمة على قصاصة بيضاء، فوق منطقة أزرار التطبيقات.

## 8. نهاية كل فيديو (CTA)
- مشهد «**هدية مجانية — اكتب في التعليقات**»: الكلمة تنكتب حرف حرف داخل فقاعة تعليق، سهم لأيقونة ملف.
- كل فيديو له **كلمة** و**ملف PDF**:
  - حل 5 مشاكل ← «**مشاكل**» ← دليل حلول المشاكل الخمس.
  - PLA أم PETG ← «**خيوط**» ← ملف المقارنة.
  - لا تشترِ طابعة ← «**طابعة**» ← قائمة الفحص قبل الشراء.

## 9. الصورة المصغّرة
- **9:16** بأسلوب الريلز المرجعية: نظيفة، مساحة فاضية، ورق مربعات.
- عنوان على شريط ورق أبيض، الكلمة المهمة بخلفية وردية، وجملة ثانية أصغر.
- ملصقات صور حقيقية + تسميات صغيرة + علامة استفهام رسم خطي + خيوط وردية + سهم متقطّع.
- **نجم** بحركة تليق بالموضوع (خمس أصابع لـ «5 مشاكل»، يدين مفتوحة للمقارنة، إصبع تنبيه لـ «لا تشترِ»).
- سلسلة الخطوات تحت، وشعار HX 3D في الزاوية.
- القالب: `video-design/source/thumbnail-template-pro.html`.

## 10. ملفات PDF
- A4، نفس الهوية (ورق مربعات، وردي/أبيض/أسود، ملصقات، نجم).
- غلاف + صفحات محتوى ببطاقات + قائمة فحص بمربعات صح.
- الأرقام التقنية تقريبية، ومكتوب إن توصية الشركة المصنّعة هي المرجع.
- القالب: `video-design/pdfs/source/build.py`.
