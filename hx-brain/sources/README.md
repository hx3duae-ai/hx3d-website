# sources/

Put **all your files** here: PDFs, notes, screenshots, price lists, web clips (Obsidian Web Clipper), voice transcripts.
Claude reads them but never edits them. Then run `/second-brain-ingest` and Claude files them into `wiki/`.

- `imports/`: drop the ChatGPT and Claude export `.zip` files here.
- `chats/`: generated from those exports (one note per conversation).
- `assets/`: images and attachments.

Everything in this folder is git-ignored, so your private files stay on your computer.
