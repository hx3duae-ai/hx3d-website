# نجم (Najm) — شخصية HX 3D

نجمة نصّها أسود ونصّها وردي (`#FF66B2`)، بأيدي ورجلين وحذاء. الشخصية الرسمية اللي تشرح في فيديوهات HX 3D.

## الملفات
- `poses/najm_NNN_sK.png`: 281 وضعية مقصوصة بخلفية شفافة، محسّنة (بدون هالة، حدّة أعلى).
  - `NNN` رقم الوضعية (000–280)، و`sK` رقم اللوحة الأصلية (s0–s8).
  - كل الصور 640×640، النجمة بارتفاع ~470 بكسل ورجليها عند نفس الخط، فتتبدّل بدون ما تقفز.
- `najm_contact_sheet.jpg`: كل الوضعيات بأرقامها.

## ملاحظات
- اللوحات **s1 و s5** (وأغلب s0) بنفس شكل نجم الأصلي وبأعلى دقة — الأفضل للفيديوهات.
- اللوحات **s2، s3، s4، s8** النجمة فيها بشكل مختلف (وردي أفتح، أطراف أنعم).
- وضعيات مفيدة: 45/46 تلويح، 47 إصبع، 62 إصبعين، 51/70 إشارة، 56/57 عضلات، 63 و168/173 هزّ كتفين، 170 يد على الراس، 186/187 إبهامين، 190/191 قفز، 204/205 تمام، 179/180 تلويح باليدين، 198 يدين لفوق.
